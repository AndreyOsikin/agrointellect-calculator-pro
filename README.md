# Калькулятор стоимости Агроинтеллект

Расчёт стоимости Онлайн-фермы, Мусофт и Учёта молока. Выбор продуктов, площадки, системы, поголовье, пользователи с ИИ, формат оплаты и индивидуальная скидка.

Калькулятор работает без данных клиента и менеджера. Формирование КП, PDF и отправка писем исключены из сайта. Исходники прежнего серверного компонента в `server/` не используются и не публикуются.

## Проверка

`node --check app.js`

`node --test tests/calculation.test.cjs tests/sender.test.mjs`

## Публикация

GitHub Actions публикует `index.html`, `styles.css`, `app.js` и `assets/` из ветки `main` на GitHub Pages.
