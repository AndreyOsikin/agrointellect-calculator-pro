# Калькулятор стоимости Агроинтеллект

Калькулятор Онлайн-фермы, Мусофт и Учёта молока на основе `agrointellect_calculator_final_v5.html`.

## Возможности

- Выбор продуктов, несколько площадок, системы и дополнительные подключения.
- Тарифы по поголовью, ИИ и обычные пользователи, годовая/месячная оплата, персональная скидка.
- Проверка данных перед выпуском КП; суммы с точностью до копеек.
- Предпросмотр, копирование полного текста, скачивание PDF с кириллицей, печать.
- Передача PDF через Web Share там, где браузер поддерживает обмен файлами. Иначе — сохранение файла и ручное вложение в мессенджер.
- Открытие готового письма в почтовой программе. `mailto` не отправляет письмо автоматически и не прикрепляет PDF.
- Подготовленная интеграция SMTP Kerio Connect. До размещения серверного компонента прямая отправка недоступна; интерфейс прямо сообщает об этом.

Калькулятор не отправляет данные автоматически и не сохраняет пароли. Изменяемые тарифы — параметры конкретного расчёта, а не защищённый корпоративный прайс-лист. Они не сохраняются после обновления страницы.

## Запуск и публикация

Для локальной работы откройте `index.html`; файлы `vendor/`, `assets/`, JS и CSS должны находиться рядом. Для публикации на GitHub Pages выберите ветку `main` и корень `/` в Settings → Pages. Файл `.nojekyll` отключает обработку Jekyll.

Проверка расчётов и серверного компонента:

```sh
node --test tests/calculation.test.cjs tests/sender.test.mjs
```

Для автоматической проверки в GitHub Actions предусмотрен CI. Для Pages сервер Kerio размещается отдельно: GitHub Pages выполняет только клиентский код.

## Подключение Kerio Connect

См. [инструкцию администратора](server/SETUP.md). Реальная SMTP-отправка требует подтверждённых настроек сервера и проверки полученного письма с вложением. Подготовленные параметры в `.env.example` — пример, не подтверждённая конфигурация инфраструктуры.

## Зависимости

PDF: pdfmake 0.2.20, локальная копия с Roboto, лицензия `vendor/pdfmake.LICENSE`; [официальная документация](https://pdfmake.github.io/docs/0.1/getting-started/client-side/). SMTP: Nodemailer 10.0.16. Данные клиента и тестовые КП не входят в исходный код.
