# Прямая отправка КП через Kerio Connect

## Что подготовлено

Сервер `index.mjs` принимает письмо и PDF, авторизуется на SMTP Kerio от имени менеджера и возвращает успех только после принятия письма SMTP-сервером. Это не подтверждение доставки получателю. Пароль передаётся один раз по HTTPS, не записывается в файлы и не логируется приложением.

## Что должен подтвердить администратор

1. SMTP-хост и порт (465 с TLS либо 587 с обязательным STARTTLS), действительный сертификат и возможность SMTP AUTH. Известный адрес веб-почты: `https://m.mustangtk.ru/`; SMTP-настройки по нему не проверены.
2. Допустимые домены почты менеджеров и правила Kerio, запрещающие подмену отправителя.
3. Сервер Node.js 24 за HTTPS reverse proxy, доступный по адресу вида `https://mail-api.example.ru/api/send-proposal`.

## Развёртывание

В каталоге `server` выполните:

```sh
npm ci
cp .env.example .env
# Заполните подтверждённые параметры .env.
npm start
```

Сервер слушает только `127.0.0.1:3000`. Reverse proxy публикует единственный маршрут `/api/send-proposal` по HTTPS. Обязательные параметры proxy: предел тела 2 МБ, таймаут не менее 35 секунд, ограничение частоты запросов по реальному IP, отсутствие записи тел запросов и паролей в логи. При необходимости разместите маршрут в корпоративной сети/SSO.

В `config.js` установите `sendEndpoint` на реальный HTTPS-адрес. `ALLOWED_ORIGIN` — точный origin калькулятора, например `https://andreyosikin.github.io`, без пути репозитория. Заполните `ALLOWED_SENDER_DOMAINS` реально используемыми доменами. В публичные файлы не помещаются SMTP-пароли или приватные токены.

## Проверка запуска

Откройте калькулятор, подготовьте тестовый КП и укажите собственный почтовый адрес получателя. Нажмите «Отправить из калькулятора», введите данные своей рабочей почты и отправьте. Проверьте полученное письмо, PDF, суммы и отправителя. Затем проверьте неверный пароль, недопустимый домен, сетевую ошибку и повторную отправку.

Без этой проверки прямая отправка считается подготовленной, но не запущенной. SMTP-отправка сама по себе не создаёт копию в папке «Отправленные» Kerio; если архив обязателен, администратору нужно настроить серверное архивирование.

Официальное описание [служб Kerio Connect](https://support.kerioconnect.gfi.com/article/114521-kerio-connect-services).
